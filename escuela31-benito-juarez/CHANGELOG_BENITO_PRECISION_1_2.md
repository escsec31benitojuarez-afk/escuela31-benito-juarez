# Benito IA — mejora de precisión 1.2

## Cambios realizados

- Reemplazo del buscador lineal por un motor local de reconocimiento de intenciones con puntuación, prioridades y tolerancia a errores tipográficos.
- Incorporación de conocimiento institucional específico extraído del sitio vigente.
- Respuestas diferenciadas para autoridades, funciones y horarios.
- Respuestas específicas para certificados, constancias, pases, inscripciones, SAGE, Aula Digital, becas, mesas de exámenes, actividades, programas, biblioteca y comedor.
- Respuestas prudentes cuando la información todavía no está publicada o debe confirmarse.
- Nueva aclaración guiada cuando la consulta es ambigua, en lugar de una derivación genérica inmediata.
- Nuevos accesos rápidos a SAGE y Becas.
- Actualización de versión de recursos a 1.2.0 para evitar caché del navegador.
