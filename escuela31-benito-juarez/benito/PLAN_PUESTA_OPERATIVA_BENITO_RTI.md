# Plan de puesta operativa de Benito RTI

## Nivel 1 — Demo funcional

Estado: completado.

Permite:
- explorar la aplicación;
- validar módulos;
- generar documentos sintéticos;
- simular tareas y memoria local.

## Nivel 2 — Piloto interno controlado

Requisitos:
- backend seguro;
- base de datos;
- autenticación real;
- perfiles institucionales;
- HTTPS;
- copias de seguridad;
- registro centralizado de auditoría;
- aprobación institucional;
- protocolo de datos.

## Nivel 3 — Operación institucional

Requisitos adicionales:
- carga de datos reales autorizados;
- capacitación de usuarios;
- soporte;
- políticas de conservación y eliminación;
- revisión periódica de permisos;
- integración gradual con herramientas externas;
- evaluación del piloto.

## Criterio de salida

Benito RTI no debe considerarse operativo con datos reales hasta completar el Nivel 2.
