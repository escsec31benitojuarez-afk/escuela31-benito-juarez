# Protocolo de calidad de respuestas

## Principios

1. Responder únicamente con conocimiento institucional disponible.
2. Priorizar contenidos validados.
3. Mostrar las fuentes utilizadas.
4. Señalar confianza baja o ausencia de evidencia.
5. No inventar datos faltantes.
6. Derivar consultas sensibles o de alto riesgo.
7. No procesar datos personales innecesarios.

## Niveles de confianza

- **Alta:** coincidencia sólida y varias evidencias validadas.
- **Media:** evidencia pertinente, pero limitada.
- **Baja:** coincidencia parcial.
- **Sin evidencia:** no existe contenido validado suficiente.

El porcentaje es orientativo y no representa una probabilidad estadística.
