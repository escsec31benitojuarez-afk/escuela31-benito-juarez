# Fase — Dashboard Ejecutivo SPA

Se incorpora un único escritorio operativo para Benito IA.

## Punto de entrada

- `login.html` autentica y redirige a `dashboard.html`.
- `private-dashboard.html` conserva compatibilidad y redirige al nuevo tablero.

## Navegación integrada

Inicio, Inteligencia Educativa, RTI, Equipo Directivo, Asesoría Pedagógica, Docentes, Documentos, Multimedia, Memoria Institucional, Agentes IA y Configuración.

## Alcance

El tablero funciona como una Single Page Application para la navegación principal. Los módulos especializados existentes siguen abriéndose como páginas completas, manteniendo la funcionalidad desarrollada y evitando duplicaciones.

## Seguridad

Versión demostrativa con datos sintéticos y persistencia local. No utilizar con datos personales reales.
