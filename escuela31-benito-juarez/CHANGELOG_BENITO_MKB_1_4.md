# Benito IA 1.4 — Motor de Conocimiento Institucional

## Cambios reales
- Se separó la base de conocimiento del motor conversacional.
- Nueva estructura `benito/conocimiento/` y `benito/motor/`.
- Se conservaron todos los flujos funcionales de SAGE, pases y becas.
- Se incorporaron escenarios para analítico/título, asistencia, horarios, materias previas, tutorías, convivencia, docentes, familias, calendario y privacidad.
- Se añadieron sugerencias relacionadas después de algunas respuestas.
- Se mantiene el funcionamiento 100 % local, sin API externa.

- `benito/index.html`
- `benito/conocimiento/benito-conocimiento.js`
- `benito/motor/benito-motor.js`
- `benito/benito-publico.css`
