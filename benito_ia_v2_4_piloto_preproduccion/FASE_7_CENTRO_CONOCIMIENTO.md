# Fase 7 — Centro de Conocimiento Institucional

## Incorporaciones

- Base institucional estructurada en JSON.
- Esquema de validación.
- Estados: pendiente, validado y observado.
- Fuentes asociadas a cada entidad.
- Relaciones entre contenidos.
- Buscador y filtros.
- Editor local.
- Importación y exportación de conocimiento.
- Exportación de fragmentos preparados para RAG.

## Uso

1. Abrir `admin.html`.
2. Revisar las entidades.
3. Editar títulos, resúmenes, palabras clave y estado.
4. Exportar el JSON actualizado.
5. Exportar los fragmentos RAG cuando se necesiten.

## Seguridad

La herramienta funciona localmente. No publica cambios ni modifica el sitio institucional.
