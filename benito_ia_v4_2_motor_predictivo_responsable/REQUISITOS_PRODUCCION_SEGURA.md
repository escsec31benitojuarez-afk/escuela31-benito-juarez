# Requisitos para producción segura

- Backend seguro.
- HTTPS.
- Base de datos protegida.
- Argon2id o bcrypt.
- Cookies HttpOnly, Secure y SameSite.
- Autorización del lado servidor.
- Auditoría centralizada.
- Copias cifradas.
- Separación desarrollo, staging y producción.

Ocultar botones no constituye seguridad.
