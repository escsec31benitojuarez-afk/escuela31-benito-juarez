# Benito Portal v2.0.0 — Notas técnicas

## Objetivo
Transformar la página inicial en una Recepción Digital sin alterar el funcionamiento del sitio institucional existente.

## Archivos modificados
- `index.html`
- `styles.css`

## Archivos agregados
- `CHANGELOG_BENITO_PORTAL.md`
- `NOTAS_TECNICAS_BENITO_PORTAL_V2.md`

## Compatibilidad
La actualización conserva las rutas HTML actuales y no requiere servidor, compilación ni dependencias externas. Puede publicarse con el mismo flujo de GitHub Desktop utilizado hasta ahora.

## Seguridad
La experiencia pública aclara expresamente que no expone información personal, calificaciones ni datos privados. El acceso institucional continúa separado mediante `benito/login.html`.

## Reversión
La versión anterior puede recuperarse desde el historial de GitHub. No se eliminaron páginas ni recursos existentes.
