# Protocolo del piloto institucional

## Alcance sugerido

- Duración inicial: dos semanas.
- Participantes: equipo directivo, asesoría pedagógica, RTI y un grupo reducido de docentes.
- Segunda ronda: estudiantes y familias seleccionados.
- Entorno: copia privada o staging.

## Indicadores

- Consultas realizadas.
- Porcentaje de respuestas útiles.
- Consultas sin evidencia.
- Errores de recuperación.
- Tiempo medio de respuesta.
- Derivaciones humanas.
- Problemas de accesibilidad.
- Incidentes de privacidad.

## Criterios para avanzar

1. No se registran datos personales.
2. Las fuentes se muestran correctamente.
3. Las consultas críticas se derivan.
4. Al menos el 80 % de respuestas de prueba son valoradas como útiles.
5. Los contenidos centrales están validados.
6. Existe un responsable institucional del conocimiento.
7. El equipo aprueba la incorporación al entorno público.
