# Checklist de preproducción

## Conocimiento
- [ ] Autoridades verificadas.
- [ ] Teléfono y correo verificados.
- [ ] Enlaces de Aula Digital revisados.
- [ ] Becas y SAGE actualizados.
- [ ] Contenidos pendientes identificados.
- [ ] Responsable de actualización definido.

## Seguridad
- [ ] Sin claves en JavaScript.
- [ ] Sin datos personales en registros.
- [ ] Endpoint institucional protegido.
- [ ] Política de privacidad publicada.
- [ ] Límites de uso configurados.
- [ ] Procedimiento de incidentes aprobado.

## Calidad
- [ ] Banco de evaluación aprobado.
- [ ] Consultas de estudiantes probadas.
- [ ] Consultas de familias probadas.
- [ ] Consultas docentes probadas.
- [ ] Respuestas sin evidencia verificadas.
- [ ] Derivaciones humanas verificadas.

## Accesibilidad
- [ ] Navegación por teclado.
- [ ] Indicadores de foco.
- [ ] Lectores de pantalla.
- [ ] Contraste.
- [ ] Vista móvil.
- [ ] Reducción de movimiento.

## Despliegue
- [ ] Copia de seguridad.
- [ ] Entorno de staging.
- [ ] Aprobación institucional.
- [ ] Plan de reversión.
- [ ] Monitoreo posterior.
