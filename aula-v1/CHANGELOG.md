# Registro de cambios

## 1.0.0 — 2026-08-24

- Se creó el módulo independiente `/aula-v1/` sin modificar el Portal público.
- Se implementaron ingreso por usuario simple, sesión, autorización por perfil, curso dinámico y cierre de sesión.
- Se incorporaron Biología, Lengua y Literatura y Matemática como materias piloto.
- Se agregaron estados de carga, conexión, cuenta inactiva y acceso denegado sin pantallas en blanco.
- Se agregó esquema relacional y RLS para perfiles, cursos, materias, relaciones y asignaciones docentes.
- Se documentó la activación institucional pendiente y la matriz mínima de pruebas.
